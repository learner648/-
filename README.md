1. Demo 简介

是什么：一款基于 Web 网页端的青少年情绪疏导与认知重塑多角色互动对话系统。

面向谁：面临学业压力、人际交往困扰，容易产生情绪内耗和焦虑的 12-18 岁青少年，特别是缺乏专业心理支持渠道的下沉市场/偏远地区学生。

主要功能：**思维破壁机：**系统自动捕捉聊天输入中的绝对化词汇（如“一定”、“永远”、“绝不”），触发交互拦截，引导用户将其替换为可能性词汇，用可视化的方式打破“非黑即白”的认知死胡同。

多智能体群聊陪伴：内置三位虚拟伙伴——共情猫（负责情绪接纳）、理智狗（负责逻辑拆解）、脑洞鸟（负责发散多元视角），模拟无压力的同龄人群聊氛围，告别单调爹味的 AI 问答。

2. Demo 创作思路

灵感来源：传统心理咨询门槛高、有“病耻感”，普通 AI 陪聊又缺乏心理学支撑且容易“爹味说教”。因此，我想结合认知行为疗法（CBT）与多智能体技术，做一款有温度的数字互助工具。

想解决的问题：人在情绪低落时极易陷入灾难化内耗，无法自我觉察。而传统的心理咨询门槛高、具有“病耻感”；现有的普通 AI 助手又常常显得生硬说教，缺乏有效的情感共鸣和循序渐进的认知引导。

为什么做这个方向：我坚信“社会公益”产品的底色是普惠。选择做轻量级的 Web 网页端，是为了实现真正的“零门槛”——无需下载安装，只要有网就能随时访问，成为青少年深夜独处时 24 小时在线的“心理缓冲垫”。用多智能体的形式，则是为了最大程度卸下青少年的心理防备。
